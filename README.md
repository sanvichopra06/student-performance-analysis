# Student Performance Analysis
## Objective
This project analyzes student exam performance using Python to understand
pass rates, average marks, and overall performance trends.

## Dataset
The dataset consists of student marks ranging from 0 to 100.

## Analysis Performed
- Data validation
- Pass/fail classification
- Pass percentage calculation
- Average marks computation
- Insight generation

## Tools Used
- Python
- Jupyter Notebook

## Key Insights
- Majority of students passed the exam
- Average marks indicate moderate performance
- Some students are close to the pass threshold, suggesting targeted academic support
